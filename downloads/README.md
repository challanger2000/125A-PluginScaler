# PluginScaler 0.1 — Windows-Testpaket

Das ZIP enthält den VST3-Wrapper, x64-/x86-Helper, eigene synthetische Testplugins, Lizenzen und Prüfnachweise. Quellstand: `2fbc291d90543179cb84762e004feab83f8a93bf`.

Auf der ZIP-Dateiseite oben **Download raw file** wählen. Bei einem privaten Repository muss der Browser mit einem berechtigten GitHub-Konto angemeldet sein. Den SHA-256-Vergleichswert enthält `SHA256SUMS.txt`.

Dies ist der unveränderte Windows-Cross-Build, dessen x64-Programme unter Wine getestet wurden. Native Windows-11-, Studio-One-, Pro-53-/FM7- und x86-Laufzeitprüfungen sind noch offen. Keine Produktfreigabe. Anleitung und vollständige Einschränkungen stehen im ZIP in `README.md` und `docs/VALIDATION.md`.

Dieser gesonderte Downloadbranch verändert keine bestehenden Entwicklungszweige.
